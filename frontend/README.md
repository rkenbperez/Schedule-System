# Frontend

The frontend is **not implemented** in this repository yet. The planned client
is a React + Vite single-page application that will consume the Django REST API.

Until it is scaffolded, use:

- the Swagger UI at `http://127.0.0.1:8000/api/schema/swagger-ui/`
- the ReDoc page at `http://127.0.0.1:8000/api/schema/redoc/`
- the API reference in [`docs/api-reference.md`](../docs/api-reference.md)

The backend setup and account workflow are in
[`backend/README.md`](../backend/README.md). Architecture and container
assumptions for the planned frontend are in
[`docs/architecture.md`](../docs/architecture.md).
